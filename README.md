fb-clone-website 📘

A fake Facebook website clone — built purely for learning purposes.

This project holds a special place for me: it's the first-ever repository I created while following a Git & GitHub tutorial. It doesn't represent a fully functional social media platform, but rather a hands-on exercise to understand how Git works, how repositories are structured, and how version control fits into a real development workflow.

📖 About This Project

This repo is a clone/replica of Facebook's front-end design, created to practice:

Setting up a Git repository from scratch
Making commits and understanding commit history
Branching and merging basics
Pushing and pulling changes to/from GitHub
General front-end structuring (HTML/CSS/JS, depending on what you used)

It is not affiliated with, endorsed by, or connected to Facebook/Meta in any way. This is purely an educational clone meant to mimic the visual layout of the platform.

🎯 Purpose

The goal of this repository was never to build a production-ready application, but to:

Get comfortable with Git commands (init, add, commit, push, pull, clone, etc.)
Understand how GitHub repositories work
Practice organizing a basic web project
Build confidence before working on bigger, real-world projects
